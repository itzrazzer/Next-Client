# NextFam Client 4.0 (Fabric, Minecraft 1.21.11, Java 21)

Build: push ke GitHub -> Actions -> artifact NextFam-Client (NextFam-Client.jar).
Lokal: gradle build (Gradle 9.2.1 + JDK 21) -> build/libs/.
Pakai: taruh jar + Fabric API 1.21.11 di folder mods. Buka menu: Right Shift.
Config: config/nextfam/ (hud-layout.json, hud-settings.json, themes.json, animations.json, keybinds.json, profiles/).
